# Dev Snippets

A growing collection of reusable code snippets, organized by language and purpose.

The repository is built progressively as I learn and practice different programming concepts. Snippets may evolve over time as I discover better approaches and improve my development skills.

## Repository Structure

Snippets are grouped by programming language and purpose to keep the repository simple and easy to navigate.

```text
dev-snippets/
├── java/
│   ├── files/
└── README.md
```

## Java

### Files

| Snippet                | Description                                                 |
| ---------------------- | ----------------------------------------------------------- |
| `createDirectory.java` | Creates a directory or a complete directory structure.      |
| `createFile.java`      | Creates a new file if it does not already exist.            |
| `deleteFile.java`      | Deletes the specified file if it exists.                    |
| `normalizePath.java`   | Normalizes a path using the system-specific file separator. |
